# Architecture guide

Start with [AGENTS.md](../../AGENTS.md). Read the notes for the area you change.

- Task tracking: [Beads workflow](beads.md).
- Project templates or bootstrap: [delivery kit boundary](delivery-kit.md).
- Add one note per module or boundary: layers, data flow, contracts, persistence, security.
- Link each note here with the condition that selects it.

Each note describes implemented behavior and names concrete source paths. Confirm behavior in the code before you change it.
Update the affected notes in the same task as the architecture change.
